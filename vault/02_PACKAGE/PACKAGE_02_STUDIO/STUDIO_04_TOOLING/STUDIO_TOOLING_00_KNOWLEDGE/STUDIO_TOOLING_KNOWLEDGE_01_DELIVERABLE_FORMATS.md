# STUDIO_TOOLING_KNOWLEDGE_01 - Deliverable Formats

## Objet

Lister les formats de livrables digitaux courants et ce que le brief doit
fixer pour chacun. Les dimensions exactes par plateforme evoluent : elles sont
confirmees dans le brief de chaque projet, pas dans ce document.

---

## 1) Image

- **PNG** : transparence, aplats, interface.
- **JPG** : photo, poids reduit.
- **WebP** : web, poids reduit.
- **SVG** : logo, pictogramme, illustration vectorielle.
- Espace couleur ecran : sRGB par defaut.

## 2) Video et motion

- **MP4 (H.264)** : diffusion web et reseaux.
- Ratios courants : 16:9, 1:1, 4:5, 9:16.
- A fixer au brief : duree, cadence, son ou muet, sous-titres.

## 3) Web

- prototype : lien de preview + export des sources si prevu au brief.

## 4) A fixer dans le brief pour chaque livrable

- format, dimensions ou ratio, poids maximal si contraint,
- nombre de declinaisons,
- master fourni ou non (et format du master),
- plateforme de destination.
