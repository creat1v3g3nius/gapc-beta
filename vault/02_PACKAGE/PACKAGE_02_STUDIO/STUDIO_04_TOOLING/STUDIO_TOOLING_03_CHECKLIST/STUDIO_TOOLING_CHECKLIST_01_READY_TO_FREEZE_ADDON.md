## Objet

Points studio a ajouter a `CHECKLIST_03_READY_TO_FREEZE` : projet **pret pour
BAT** (`STUDIO_DISCIPLINE_01_GEL_RULES`).

## Checklist

- [ ] chaque livrable du brief a un CO `Done` ou un retrait decide
- [ ] formats, ratios et declinaisons conformes au brief
- [ ] revue de coherence DA faite sur l ensemble des livrables
- [ ] evidence pack present pour chaque asset genere
- [ ] rights check `PASS` pour chaque livrable
- [ ] noms de fichiers conformes a la convention studio
- [ ] masters presents dans le stockage externe
- [ ] journal de revue a jour, aucun retour non classe
- [ ] aucune donnee client dans le repo
